Range Sum of BST
1. Problem
Даются BST и два числа low и high.
Надо сложить значения всех узлов, чьё значение попадает в [low, high], границы включены.
Все значения уникальны.

2. Approach
Подход A: brute force
Просто рекурсивно обхожу всё дерево (DFS).
В каждом узле проверяю low <= root.val <= high, если да то добавляю к сумме.
Потом прибавляю результаты левого и правого поддеревьев, null даёт 0.
Правильно, но дерево - BST, а я обхожу как обычное, всегда все n узлов.

Подход B: с отсечением (используем BST)
Тут уже три случая для текущего узла:
1. root.val < low: узел и всё его левое поддерево меньше low, там ничего не найдём. Идём только вправо
2. root.val > high: узел и всё правое поддерево больше high. Идём только влево.
3. low <= root.val <= high: берём узел и идём в обе стороны, потому что и слева, и справа могут быть подходящие значения.
Суть в том чтобы не заходить в поддеревья, которые точно вне нужного диапазона.

Трассировка: root = [10,5,15,3,7,null,18], low = 7, high = 15
        10
       /  \
      5    15
     / \     \
    3   7     18

1. 10  -> в диапазоне -> 10 + левое(5) + правое(15)      
2. 5 -> 5 < 7 -> левое (3) не трогаем, идём в 7    
3. 7 -> в диапазоне -> 7 + null + null = 7                      
4. 15 -> в диапазоне -> 15 + null + правое(18)           
5. 18 -> 18 > 15 -> идём влево, там null, вклад 0                 |
Итого: 10 + 7 + 15 = 32. Узел 3 вообще не посещали, это и есть отсечение

Первая версия brute force. Заработала но делает лишнее.
В первой попытке при root.val < low я все равно шла в обе стороны. 
Получается отсечения нет и алгоритм превращается обратно в brute force. 
Нужно было реально возвращаться только в одну сторону.

3. Time Complexity
Brute force: O(n).
Каждый узел посещается ровно один раз, работа за O(1).
С отсечением: худший случай всё ещё O(n). Если диапазон покрывает почти всё дерево, придётся обойти всё.

4. Space Complexity
O(h)
Память уходит только на стек рекурсии, а его глубина не больше высоты дерева.
Для сбалансированного это O(log n), для вырожденного O(n).
