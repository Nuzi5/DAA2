Search in a Binary Search Tree
1. Problem
Нам дают корень BST и число val. Нужно найти узел со значением val и
вернуть его вместе со всем поддеревом. Если такого узла нет, вернуть null.
Это Binary Search Tree, то есть слева всегда меньше, справа всегда больше. Именно это и используем.

2. Approach
На каждом узле сравниваем val с node.val:
если равно —> нашли, возвращаем этот узел
если val меньше —> значит нужный узел может быть только слева, идём влево
если val больше —> только справа, идём вправо
если дошли до null —> значит значения в дереве нет.
То есть мы не ищем по всему дереву, а просто спускаемся по одному пути.
Я сделала это циклом while, без рекурсии, один указатель root идёт вниз.

Трассировка 1: root = [4,2,7,1,3], val = 2
        4
       / \
      2   7
     / \
    1   3

1. Узел 4, сравниваем 2 < 4 ->идём влево
2. Узел 2, сравниваем 2 == 2 -> нашли, возвращаем
Ответ: поддерево [2,1,3]

Трассировка 2: тот же корень, но val = 5
1. Узел 4, сравниваем 5 > 4 ->идём вправо  
2. Узел 7, сравниваем 5 < 7 ->идём влево     
3. null -> значит такого узла нет 
Ответ: null

Тестировала на двух кейсах: когда значение есть (пример 1) и когда нет(пример 2). 
Ещё руками прогнала дерево, где val больше всех -> уходит вправо до null.
Также при написании цикла (while) главное было не забыть проверить root != null перед обращением к root.val, 
иначе код падал бы с NullPointerException на пустом дереве.

3. Time Complexity
O(h) где h это высота дерева
За одну итерацию мы спускаемся ровно на один уровень и делаем O(1) работы (одно сравнение и одно присваивание указателя).
Максимум итераций = высота дерева.
Но, Сбалансированное дерево: h = log n → O(log n).
Вырожденное (когда все в одну сторону): h = n → O(n), это худший случай

4. Space Complexity
O(1)
Держим только один указатель root, новых структур не создаем. 

5. Reflection / Improvement
Можно ли лучше? В рамках обычного BST нет, поиск уже оптимальный так как идём по одному пути от корня.
Что бы улучшил? Форму дерева. 
Какая сложность достижима? O(log n) в худшем случае, за счёт балансировки.
